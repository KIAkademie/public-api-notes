# Public-API Tester & Notiz-Speicher

Ein schlichtes Werkzeug zum Testen öffentlicher JSON-Schnittstellen (REST-APIs) und zum lokalen Speichern von eigenen Notizen und Code-Snippets im Browser (`localStorage`).

- **Live-Anwendung:** [https://kiakademie.github.io/public-api-notes/](https://kiakademie.github.io/public-api-notes/)
- **Autor:** Joel Neto Romeira

## Funktionen

- **Öffentliche APIs testen:** Vorbereitete oder eigene GET-Abfragen an öffentliche Schnittstellen senden und die JSON-Antwort übersichtlich formatiert ansehen.
- **Lokale Notiz- & Snippet-Datenbank:** Wichtige API-Endpunkte oder eigene Notizen lokal anlegen, filtern und löschen.
